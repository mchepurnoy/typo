# Distribute outside the Mac App Store

typo must observe every keystroke system-wide and re-type words, which needs a CGEventTap with Accessibility permission; the App Store sandbox does not allow that. We ship publicly as a Developer ID-signed, notarized download from our own landing page instead, as other layout switchers do.

## Consequences

- Requires a paid Apple Developer Program membership before the first public release; during development a free Personal Team certificate is enough.
- We own updates ourselves (no App Store update channel).
